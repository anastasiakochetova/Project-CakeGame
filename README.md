# 🍰 CakeGame — Собери идеальный торт!

**CakeGame** — это обучающая WinForms-игра на C#. Игроку нужно собрать слой за слоем торт, соответствующий случайно выбранному эталону, используя бисквиты и крем разных цветов.

## 🎮 Игровой процесс

1. **Выбор бисквита** — нажмите на один из 4 тижей слева, чтобы добавить слой основы.
2. **Выбор крема** — кликните на цветную палитру справа, затем нажмите на нужный слой торта.
3. **Удаление слоёв** — нажмите на любой слой торта, чтобы удалить его.
4. **Проверка результата** — нажмите кнопку **"Сравнить"**, чтобы оценить сходство с целевым тортом.
5. **Сброс прогресса** — кнопка **"Новая игра"** полностью перезапускает раунд.
6. **Корзина** — нажмите на иконку корзины, чтобы очистить всю сборку.

> 💡 **Цель:** достичь 100% совпадения с загаданным тортом за минимальное количество попыток. За каждое неверное сравнение отнимается жизнь.

## 🕹️ Управление

- **Мышь** — всё взаимодействие через клики.
- **Hover** на корзине подсвечивает её.

## 🧠 Система игры

- **Правильные слои** — зелёная подсветка.
- **Лишние/недостающие слои** — красная подсветка и тряска экрана при неверном результате.
- **Частицы** — при добавлении/удалении слоя вылетают красивые эффекты.
- **Таймер** — игровое время ограничено.

## 🛠️ Технологии

- **.NET Framework 4.8**
- **Windows Forms** (чистый GDI+ рендеринг)
- **Язык C# 9.0**
- Архитектура: **Model-View-Controller + TimerManager**

## 🚀 Запуск

1. Откройте `CakeGame.sln` в **Visual Studio 2019+**.
2. Убедитесь, что выбран **.NET Framework 4.8**.
3. Нажмите `F5` для сборки и запуска.

## 🧪 Возможные доработки

- Сохранение рекордов.
- Сложность (ограничение по времени).
- Анимация вращения торта.
